# Seu Sonho em Linhas

Protótipo do site institucional e portfólio de Victor Muller Arquitetura.

## Tecnologias

- React
- Vite
- CSS responsivo
- Lucide React

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

## Produção

```bash
pnpm build
pnpm preview
```

As imagens identificadas na interface como demonstrativas serão substituídas pelos materiais oficiais do portfólio.
